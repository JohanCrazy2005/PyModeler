# Keyboard Shortcuts

## Navigation
- Drag: Orbit
- Shift + Drag: Pan
- Wheel: Zoom
- Home: Frame All
- F: Frame Selected

## View
- Z: Cycle shading mode (Solid / Wireframe / Solid+Edges)
- 1: Front view
- 3: Right view
- 7: Top view
- 5: Toggle Perspective / Orthographic

## Gizmo
- G: Translate mode
- R: Rotate mode
- S: Scale mode

## Edit
- Ctrl+Z: Undo
- Ctrl+Shift+Z: Redo
- Delete: Delete selected

These are also available via the menus.
